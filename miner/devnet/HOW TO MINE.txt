SUMO FROG MINER for Windows  (test coins on Solana devnet: no real money)
=========================================================================

First time on this PC (or updating the old folder)
1. Close any miner window that's still running.
2. Right-click the zip and choose "Extract All...", then click Extract. This makes a folder
   with SUMO Frog.bat (the launcher) and START HERE.txt on top, and a "files" folder
   with everything else.
3. Updating from the older flat version? Extract into the SAME folder and say "Replace the files".
   Your wallet file sumo-devnet-key.json (and payout-address.txt, if you set one) moves into the
   "files" folder by itself the first time you run SUMO Frog.bat.
   NEVER delete sumo-devnet-key.json, wherever you find it: it holds your test SUMO.
   If the miner says "Two wallets found" (or that it couldn't move the wallet), it has stopped on
   purpose and made no new wallet. Don't delete anything. Keep the wallet you want in the "files"
   folder and put the other somewhere safe, for example a folder called "old wallet".
   The old buttons and program files left in the folder (the old .bat files, sumo_miner.py, .venv
   and so on) are no longer used and can be ignored.
   If you extract somewhere new instead, MOVE sumo-devnet-key.json (cut and paste, do not copy)
   from the old folder into the new "files" folder yourself, so only one wallet file is left.
   The wallet is NOT in the zip.
4. This zip is already set to the public Solana devnet (files\sumo_config.json is included).
   There is nothing to edit. You need Python 3 installed (python.org, tick "Add python.exe to PATH").
5. Open that folder and double-click  SUMO Frog.bat . A numbered menu appears:
     1 Mine SUMO   2 Check balance   3 Get test SOL   4 Set payout address   5 Withdraw SOL   6 Exit
   Press 1. The first time, it makes a test wallet and shows its address, then says it needs test SOL.
   Get free devnet SOL at https://faucet.solana.com (sign in with GitHub, pick Devnet,
   paste that address; menu option 2, Check balance, shows it again), then press 1 again.
6. If Windows asks whether to run it, click "Run". If it says "Windows protected your PC",
   click "More info" then "Run anyway". (It's a plain text script: right-click it and
   choose "Edit" to see exactly what it does.)
7. The first run sets itself up for a minute. Then mining starts.
   The box on the right says  >> MINING...  while it works, and
   *** BLOCK FOUND! +20 SUMO ***  when you win a block.
8. To stop, press Ctrl+C or close the window. If Windows asks "Terminate batch job (Y/N)?",
   type N to go back to the menu, or Y to close. After anything except mining, the menu comes back.

What the numbers mean
- BLOCK       the block everyone is racing for right now
- HASH/S      how many guesses your PC makes per second
- GUESS #     how many guesses it has made on this block so far
- DIFF        how hard a block is (each +1 doubles the work)
- REWARD      SUMO for winning a block (20 now; it halves once a year)
- MINED       blocks you've won since you opened the window
- BALANCE     SUMO in the wallet your rewards go to
- HALVING IN  blocks left until the reward halves

Sending rewards to your own wallet (optional)
- In the menu, press 4 (Set payout address) and paste your wallet's PUBLIC address
  (the one you'd share to receive coins). Type YES to confirm.
- From then on the miner sends each reward there. The miner's own test wallet
  still pays the tiny test fees.
- NEVER type a seed phrase or private key into the miner or anything else.
  The miner refuses them and never asks for them.
- To go back to the miner's own wallet, choose it again and type  none

Taking your test SOL back out (optional)
- In the menu, press 5 (Withdraw SOL) when you've finished mining on this PC.
- Paste your wallet's PUBLIC address, or press Enter to use your payout address.
- It shows how much test SOL it will send and where, then asks  y/N  first.
  It sends all of it minus the tiny fee, so the miner's wallet ends at 0.
- If the miner's wallet holds SUMO too (no payout address), it asks if you
  want to send that as well.
- It refuses seed phrases, private keys, program addresses and the miner's
  own address, and never asks for a key.
- To mine again afterwards, get test SOL first (menu option 3, Get test SOL).

Other menu options
- 2 Check balance : shows your SUMO, your test SOL and the network stats.
- 3 Get test SOL  : on public devnet this usually fails; use https://faucet.solana.com instead.

If the colours or pictures look wrong
- Make the window wider (about 100 columns) to see the frog, or run
  SUMO Frog.bat from a newer terminal. Plain text mode:  open a Command Prompt in the "files" folder and run  .venv\Scripts\python.exe sumo_miner.py mine --plain

If it says Python isn't installed
- Install it from https://www.python.org/downloads/ and tick "Add python.exe to PATH",
  then double-click SUMO Frog.bat again.
  (If the "files" folder already has a .venv from PyCharm, it just reuses that.)
